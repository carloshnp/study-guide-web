# FIG-10-05: Drill gate: rule, hand table, code
status: draft   rev: 1   date: 2026-10-22   author: illustration spec agent

## 1. Summary
One square flat diagram of the drill gate. Three blocks sit in one row in the order the drill demands: rule first, hand table, then code. The first two blocks are accent. The third is locked: it has a heavier warning border, a warning bar across its width that carries the note locked until both pass, and a gate line stands before it. A checklist strip beneath the blocks shows two checked cells and one cell not yet checked. No value, table cell or code text is drawn. The picture carries the order of the gates; every claim it makes is in the ledger in section 4.
MESSAGE: A drill is passed only after its rule and its hand table are on the page, before any code is typed.

## 2. Communicative intent
- AUDIENCE: an exam-revising student who has met stacks, queues, heaps and graphs, has read the knapsack drill in prose, and believes that coding the answer first is the quicker route to a correct result.
- INTENDED CHANGE: believe that the code step stays locked until a stated rule and a hand-filled table exist, and that a wrong hand table shows the mistake before any code does.
- READING CONTEXT: study-site chapter 10, section 10.5, anchor 105-practice-knapsack-and-tournament-drills, shown beside the drill paragraph at column width. Light theme and dark theme both shown; the card plate stays light in both, so the figure does not change ground between themes. Phone readers open it in the lightbox at two times.
- REPRODUCTION: square raster, reference 1000 by 1000 px; displayed up to 1050 px wide in the article column; phone lightbox at 2x.
- LIFETIME: one chapter illustration system; line grammar and palette shared with FIG-10-01 to FIG-10-06.

## 3. Goals and non-goals
- GOAL-1: the reader sees three blocks in drill order, left to right, each carrying its label: rule first, hand table, then code.
- GOAL-2: the code block reads as locked from the picture alone: a heavier warning border, a warning bar across its width, and the note locked until both pass.
- GOAL-3: a gate line labelled pass gate stands between the hand table and the code block, and no arrow crosses it.
- GOAL-4: the checklist strip beneath shows two checked cells and one not yet cell, in the same order as the three blocks.
- NON-GOAL-1: knapsack values, weights, capacities and table cells. No value appears in any form.
- NON-GOAL-2: code text, a listing or a Rust sketch. The code block is a locked shape and nothing more.
- NON-GOAL-3: the tournament exercise, a scoreboard or the tie-breaking rule of section 10.5.2.

## 8. Composition plan
- DOMINANT: the locked code block, its heavier warning border and the warning bar across it.
- FOCAL MECHANISM: three of six: hue contrast (the warning bar against the wash block and the white plate); size (the heavier border and the full-width bar); isolation (the only wash-filled block in a row of accent blocks).
- HIERARCHY: three levels. Level one, the three blocks and the warning bar. Level two, the gate line and the checklist strip. Level three, the arrow and the small labels pass gate, checked and not yet.
- READING PATH: rule first, arrow, hand table, pass gate, locked code block, checklist strip.
- FRAMING: the plate fills the square; the blocks occupy the band from top 36 to 60 percent; the checklist strip closes the lower band; the top band above the gate label stays empty.
- NEGATIVE SPACE: the gap between the arrow and the gate line holds nothing, so the eye moves one gate at a time; the space below the strip stays empty.
